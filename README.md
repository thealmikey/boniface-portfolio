# Boniface Mwangi — Portfolio

Personal online resume for Boniface Ngeene Muni, Forklift Operator & Plant Operator.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Deploy to Vercel

1. Create a new repository on GitHub under `thealmikey`
2. Push this repo to GitHub
3. Import the repo in the Vercel dashboard
4. Vercel will auto-detect Vite and deploy

## Update Content

Resume data lives in `src/App.tsx`. Edit the `cv` object to update the displayed content.
